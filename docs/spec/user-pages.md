# ユーザーページ 仕様

Steam でログインした人が、自分の遊んだランの一覧を見て、公開・非公開と削除を決められるようにする。
画面の構成・見た目の部品は [`ui.md`](./ui.md) に従う。HTTP API は [`api.md`](./api.md) の「ログイン」と「ユーザー」に書く。

## 登場する人

- **記録した人**: mod でセッションを作った人 (`sessions.host_steam_id`)。そのランの公開・非公開と削除を決める。
- **参加者**: ランに参加した全員 (記録した人を含む)。ラン開始の記録 (`run_start`) の `player_id` で決まる。
  自分のユーザーページにそのランを載せるかどうかを選べる。
- **見る人**: ページを開いた人。Steam でログインしていれば、その Steam ID で本人かどうかを決める。

## ログイン

- web の画面の右上に「Steam でログイン」を置く。押すと Steam の公式のログイン (OpenID 2.0、`https://steamcommunity.com/openid/login`) に移り、承認すると元の画面に戻る。
- backend は、戻ってきたときに Steam へ検証 (`openid.mode=check_authentication`) を問い合わせ、`is_valid:true` のときだけ、`openid.claimed_id` の末尾の Steam ID を本人として受け付ける。
- ログインの状態は、backend が署名した cookie (`sts2stats_auth`、HttpOnly・Secure・SameSite=Lax、有効期限 30 日) に持つ。署名の鍵は backend が初回の起動時に作って DB に保存する。
- ログイン中は、画面の右上に自分の名前 (自分のユーザーページへのリンク) と「ログアウト」を出す。
- mod の記録の送信は、ログインとは関係なく今までどおり行う。

## ユーザーページ

URL は `/u/{steam_id}`。

### 見られる人

| 見る人 | ユーザーページの設定 | 見られるもの |
|---|---|---|
| 本人 | 公開・非公開どちらでも | 自分が参加した全部のラン (非公開のラン、ページに載せないことにしたランも含む。印を付ける) |
| 本人以外 | 公開 | その人が参加したランのうち、公開で、かつその人がページに載せているもの |
| 本人以外 | 非公開 (初期値) | 見られない。「このユーザーのページは公開されていません」と出す |

### 画面

- 見出し: 表示名 (Steam の名前。mod が記録したもの)。
- 本人のときだけ: 「ユーザーページを公開する」の切り替え。
- ランの一覧 (新しい順)。各行は 1 つのラン:
  - 日付 (`sessions.created_at`)、そのユーザーのキャラクター、アセンション、結果 (勝利 / 死亡 / 放棄 / 進行中)、到達階、一緒に遊んだ人 (名前。各人のユーザーページへのリンク)
  - 行を押すと、そのランの画面 (`/s/{id}`) へ移る
  - 本人のときだけ、行の右に操作を置く:
    - 記録した人のラン: 「公開」と「非公開」の切り替え、「削除」(確認してから消す)
    - 自分のランかどうかに関係なく: 「自分のページに載せる」の切り替え
- 一覧が空のとき: 「まだランがありません」と出す。

## ランの公開・非公開

- `sessions.visibility` が `public` (初期値) か `private`。
- `private` のランは、記録した人がログインして開いたときだけ見られる。それ以外の人がランの画面を開くと「見つかりません」と出す (backend は 404 を返す)。
- `public` のランは、今までどおり共有 URL を知っている人なら誰でも見られる。

## ページに載せるかどうか

参加者ごとの設定 (`session_players.hidden`)。載せないことにしたランは、その人のユーザーページを本人以外が見たときに出さない。ランの画面そのものの見え方は変わらない。

## 削除

記録した人だけが消せる。消すと、そのランのセッションと全部の記録がサーバから消え、元に戻せない。共有 URL は「見つかりません」になる。
mod が消したセッションに送り続けた記録は、backend が 404 を返して受け付けない。

## ランの画面からの移動

ランの画面のヘッダーの参加者名を、各人のユーザーページへのリンクにする。

## 既知の制約

- 他人の Steam ID を名乗ってセッションを作ることは防いでいない。偽のランが自分のユーザーページに載ったときは、「自分のページに載せる」を外せば隠せる。
- 複数のランをまたいだ統計は無い。
