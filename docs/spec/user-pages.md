# ユーザーページ 仕様

Steam でログインした人が、自分の遊んだランの一覧を見て、公開・非公開と削除を決められるようにする。
画面の構成・見た目の部品は [`ui.md`](./ui.md) に従う。HTTP API は [`api.md`](./api.md) の「ログイン」と「ユーザー」に書く。

## 登場する人

- **記録した人**: mod でセッションを作った人 (`sessions.host_steam_id`)。そのランの公開・非公開と削除を決める。
- **参加者**: ランに参加した全員 (記録した人を含む)。ラン開始の記録 (`run_start`) の `player_id` で決まる。
  自分のユーザーページにそのランを載せるかどうかを選べる。
- **見る人**: ページを開いた人。Steam でログインしていれば、その Steam ID で本人かどうかを決める。

## ログイン

- 共通の上の帯 (ui.md「共通の上の帯 (TopBar)」) に「Steam でログイン」を置く。ログインすると、遊んだゲームの一覧をマイページで見られる。押すと Steam の公式のログイン (OpenID 2.0、`https://steamcommunity.com/openid/login`) に移り、承認すると元の画面に戻る。
- backend は、戻ってきたときに Steam へ検証 (`openid.mode=check_authentication`) を問い合わせ、`is_valid:true` のときだけ、`openid.claimed_id` の末尾の Steam ID を本人として受け付ける。
- ログインの状態は、backend が署名した cookie (`sts2stats_auth`、HttpOnly・Secure・SameSite=Lax、有効期限 30 日) に持つ。署名の鍵は backend が初回の起動時に作って DB に保存する。
- ログイン中は、共通の上の帯に自分の名前のメニュー (マイページ・設定・ログアウト) を出す。
- mod の記録の送信は、ログインとは関係なく今までどおり行う。

## ユーザーページ

URL は `/u/{steam_id}`。

### 見られる人

| 見る人 | ユーザーページの設定 | 見られるもの |
|---|---|---|
| 本人 | 公開・非公開どちらでも | 自分が参加した全部のゲーム (非公開のゲーム、マイページに表示しないことにしたゲームも含む。バッジで示す) |
| 本人以外 | 全体に公開 | その人が参加したランのうち、公開で、かつその人がページに載せているもの |
| 本人の Steam のフレンド | Steam のフレンドに公開 | 同上 |
| 本人以外 (フレンドでない・ログインしていない) | Steam のフレンドに公開 | 見られない。「このユーザーのページは公開されていません」と出す |
| 本人以外 | 非公開 (初期値) | 同上 |

### Steam のフレンドかどうか

backend は Steam Web API の `ISteamUser/GetFriendList` (キーは環境変数 `STEAM_WEB_API_KEY`) で、ページの持ち主のフレンド一覧に、見に来た人の Steam ID があるかを調べる。
持ち主のフレンド一覧が非公開 (Steam が 401 を返す) なら、見に来た人のフレンド一覧に持ち主があるかを調べる。どちらも取れなければ、フレンドと確かめられないので見せない。
結果は 2 人の組ごとに 10 分間覚えておき、Steam への問い合わせを減らす。

### 画面

画面に出す名前は「マイページ」(本人が見るとき) で、1 回のプレイは「ゲーム」と呼ぶ。
見出しの下に「ゲーム」と「統計」のタブを置く。この節にはゲームのタブを書き、統計のタブは [`player-stats.md`](./player-stats.md) に書く。

- 見出し: 表示名 (Steam の名前。mod が記録したもの)。本人のときは、その下に「このページは非公開です。設定から公開できます。」(公開中なら「このページは公開中です。」)。
- ユーザーページを公開するかどうかは、設定の画面 (`/settings`) で切り替える。
- 絞り込み: キャラクター・ゲームモード・アセンション・結果・人数 (ソロ / マルチプレイ。参加者が 2 人以上ならマルチプレイ) のドロップダウン (どれも初期値は「すべて」)。選べる値は、一覧にあるゲームの値だけ。絞り込みは画面の中だけで行い、URL には持たない。
- ゲームの一覧 (新しい順)。1 つのゲームを 1 行にし、左から次の順に並べる (表の見出しは付けない)。640px 未満の画面では、1 行目に日付と「…」、2 行目にバッジ (折り返す)、3 行目に一緒に遊んだ人を置く:
  - 日付 (ゲームの画面 `/s/{id}` へのリンク)。キャラクターの表示名が記録されていない古いゲームは、同じキャラクターのほかのゲームの表示名を使う
  - バッジ: キャラクター、アセンション N、ゲームモード (`Standard` 通常 / `Blitz` ブリッツ / `Daily` デイリー / `Dread` ドレッド。記録の無い古いゲームでは出さない)、結果 (勝利 / 死亡 / 放棄 / 進行中)、N 階。本人のときは、非公開のゲームに「非公開」、マイページに表示しないゲームに「非表示」のバッジを足す
  - 一緒に遊んだ人 (名前。各人のユーザーページへのリンク)。長いときは省略して末尾を「…」にする
  - 本人のときは右端に「…」(ui.md「ランの設定」)
- 一覧が空のとき: 「まだゲームがありません」。絞り込みで 0 件のときは「条件に合うゲームがありません」。

## ランの公開・非公開

- `sessions.visibility` が `public` (初期値) か `private`。
- `private` のランは、記録した人がログインして開いたときだけ見られる。それ以外の人がランの画面を開くと「見つかりません」と出す (backend は 404 を返す)。
- `public` のランは、今までどおり共有 URL を知っている人なら誰でも見られる。

## ページに載せるかどうか

参加者ごとの設定 (`session_players.hidden`)。載せないことにしたランは、その人のユーザーページを本人以外が見たときに出さない。ランの画面そのものの見え方は変わらない。

## 削除

記録した人だけが消せる。消すと、そのランのセッションと全部の記録がサーバから消え、元に戻せない。共有 URL は「見つかりません」になる。
mod が消したセッションに送り続けた記録は、backend が 404 を返して受け付けない。

## ランの画面からの移動

ランの画面のヘッダーの参加者名を、各人のユーザーページへのリンクにする。

## 既知の制約

- 他人の Steam ID を名乗ってセッションを作ることは防いでいない。偽のランが自分のユーザーページに載ったときは、「自分のページに載せる」を外せば隠せる。
