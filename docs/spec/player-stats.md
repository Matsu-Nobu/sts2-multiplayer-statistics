# プレイヤーの統計 仕様

ユーザーページの「統計」タブに、その人が遊んだゲームをまたいだ統計をキャラクターごとに出す。
見られる人と見られるゲームは、ユーザーページと同じ ([`user-pages.md`](./user-pages.md)「見られる人」)。HTTP API は [`api.md`](./api.md)「ユーザー」に書く。

## 画面の構成

ユーザーページの見出しの下に「ゲーム」(`/u/{steam_id}`) と「統計」(`/u/{steam_id}/stats`) のタブを置き、どちらのタブにも同じ見出しを出す。

統計のタブは、上から次の順に並べる。

1. 絞り込み (先頭がキャラクター)
2. 区画のタブ
3. 選んでいる区画の中身

区画のタブは次の 8 つで、区画ごとに URL を分ける。リンクで共有でき、ブラウザの戻る・進むが効く。区画のタブを切り替えても、絞り込みは変えない。知らない区画の URL は概要として出す。

| 区画 | URL |
|---|---|
| 概要 | `/u/{steam_id}/stats` |
| カード | `/u/{steam_id}/stats/cards` |
| レリック | `/u/{steam_id}/stats/relics` |
| 敵 | `/u/{steam_id}/stats/enemies` |
| 進行 | `/u/{steam_id}/stats/progress` |
| エンシェント | `/u/{steam_id}/stats/ancients` |
| イベント | `/u/{steam_id}/stats/events` |
| マルチプレイ | `/u/{steam_id}/stats/multi` |

全体の勝率 (キャラクターを分けない勝率) は、どこにも出さない。

## 集計に使うゲーム

その人が参加したゲームのうち、結果が勝利か死亡のものだけを使う。放棄したゲームと進行中のゲームは使わない。
本人以外が見るときは、ゲームの一覧と同じく、公開で、かつ本人がページに載せているゲームだけを使う。

## 絞り込み

次の 6 つのドロップダウンと 1 つのチェックボックスを置く。絞り込みは URL には持たない。
ドロップダウンの値を変えると、web はキャラクターと絞り込みの条件を API に渡し、サーバが集計した結果を表示する。「5 ゲーム未満を隠す」は、受け取った表の行を web が除くだけで、API には渡さない。

| 絞り込み | 選べる値 |
|---|---|
| キャラクター | ほかの絞り込みをかけた後のゲームにあるキャラクター。ゲーム数の多い順に「フール (23 ゲーム)」の形で並べ、最初は先頭を選ぶ |
| バージョン | すべて (初期値)、ゲームにあるバージョン。新しいバージョンから「v0.113.1 (12 ゲーム)」の形で並べ、ゲーム数は絞り込む前の数。バージョンの記録が無いゲームは最後に「不明 (N ゲーム)」として出す |
| ゲームモード | すべて (初期値)、ゲームにある値 |
| アセンション | すべて (初期値)、ゲームにある値 |
| 人数 | すべて (初期値)、ソロ、マルチプレイ |
| 期間 | 全期間 (初期値)、直近 30 日 |
| 5 ゲーム未満を隠す | チェックあり (初期値)、チェックなし |

区画の数字は、すべて選んでいるキャラクターのゲームだけから出す。絞り込みで 0 ゲームになったら、区画の中身の代わりに「条件に合うゲームがありません」と出す。

「5 ゲーム未満を隠す」にチェックがあるときは、表ごとに決めた数 (各区画の「数える列」) が 5 未満の行を表から除く。
除いた結果、行が 1 つも無い表には「5 ゲーム以上の行がありません。「5 ゲーム未満を隠す」を外すと表示します。」と出す。

## 表の共通の決まり

- 表の見出しは名詞か名詞句にする (「選んだ」ではなく「選択回数」)。
- 見出しを押すと、その列で多い順に並べ替える。同じ見出しをもう一度押すと少ない順にする。並べ替えている列の見出しに ▼ (多い順) か ▲ (少ない順) を付ける。
- 最初は上から 10 行を出し、それより多ければ表の下に「すべて表示 (N 行)」のボタンを置く。押すと全部の行を出し、ボタンは「10 行だけ表示」に変わる。
- 「勝率」は、その行に当てはまるゲームのうち勝ったゲームの割合。
- 「{キャラクター名}の勝率との差」は、その行の勝率から、選んでいるキャラクターの勝率を引いた値 (パーセントの差を整数に丸める)。正なら緑で `+` を付け、負なら赤で出す。
- 割合は整数のパーセントに丸める。

## 概要

見出しは「{キャラクター名}の概要」。次の 5 つの数字の下に、「Act の突破率」(「進行」と同じ) と、「人数ごとの勝率」(「マルチプレイ」のソロとマルチプレイの勝率と同じ) を出す。

| 値 | 出し方 |
|---|---|
| ゲーム数 | ゲームの数 |
| 勝率 | そのキャラクターの勝率。下に勝ったゲーム数 |
| 平均到達階 | ゲームの最終階の平均 (小数第 1 位まで) |
| 勝利時の最高アセンション | 勝ったゲームの最大のアセンション。勝ったゲームが無ければ「—」 |
| 最長連勝 | ゲームを始めた日時の順に並べたときの、勝ちが続いた最大の数 |

## カード

カード報酬で出てきたカードごとに 1 行。ショップのある階で出てきたカード (買わなかった商品) は数えない。

表の見出しは 2 段にする。取得率と取得時の突破率は、上の段にそれぞれの見出しを置き、下の段に Act 1 から、選んでいるキャラクターのゲームで一番先に進んだ Act までの列を並べる。

| 列 | 出し方 |
|---|---|
| カード | カードの名前 (強化前)。横に長い表を横にずらしても、この列は左に残す |
| 取得ゲーム数 | どれかの Act で 1 回以上取ったゲームの数 (数える列。最初はこの列で並べる) |
| 取得率の Act N | Act N で取った回数 ÷ Act N で提示された回数。提示されていなければ「—」 |
| 取得時の突破率の Act N | Act N でそのカードを取ったゲームのうち、Act N より先の Act に進んだか勝ったゲームの割合。Act N で取ったゲームが無ければ「—」 |
| 勝率 | どれかの Act で取ったゲームの勝率 |
| 勝率との差 | 「表の共通の決まり」のとおり |

表の 1 行目には「{キャラクター名}全体」の行を置く。この行は並べ替えと「5 ゲーム未満を隠す」の対象にせず、いつも 1 行目に出す。この行の取得ゲーム数はゲーム数、取得率は「—」、取得時の突破率の Act N は Act N に進んだゲームのうち Act N を突破したゲームの割合、勝率はキャラクターの勝率、勝率との差は「—」とする。

ほかの行の取得時の突破率は、1 行目の同じ Act の値より高ければ緑、低ければ赤で出す。1 行目を Act N に進んだゲームだけで出すのは、Act N でカードを取ったゲームは、どれも Act N に進んでいるからである。

## レリック

ゲームの途中で 1 度でも持っていたレリックごとに 1 行。入手の仕方 (報酬・ショップ・エンシェント・最初から持っているもの) は区別しない。

| 列 | 出し方 |
|---|---|
| レリック | レリックの名前 |
| 所持ゲーム数 | 持っていたゲームの数 (数える列。最初はこの列で並べる) |
| 勝率・勝率との差 | 「表の共通の決まり」のとおり |

## 敵

戦った敵の組 (戦闘の部屋の敵) ごとに 1 行。

| 列 | 出し方 |
|---|---|
| 敵 | 敵の組の名前 |
| 種類 | 通常・エリート・ボスのバッジ |
| 戦闘回数 | 戦った回数 (数える列) |
| 平均被ダメージ | その戦闘の階で受けたダメージの平均 (整数) |
| 死亡回数 | その戦闘で死んだゲームの数 (最初はこの列で並べる)。1 以上なら赤で出す |

## 進行

- Act の突破率: Act 1 から、ゲームの中で一番先に進んだ Act までについて、「Act N 突破」として、Act N より先の Act に進んだか勝ったゲームの割合を出す。
- 死亡時の階: 死んだゲームの最終階ごとのゲーム数を棒グラフで出す。死んだゲームが無ければ「死んだゲームはありません」と出す。
- 休憩所の選択: 休憩所で選んだ行動 (鍛冶・休憩など) ごとに、全部の選択のうちの割合を横棒で出す。

## エンシェント

エンシェントを選ぶドロップダウンを置き、選んだエンシェントの祝福ごとに 1 行を出す。ドロップダウンには、出会った回数の多い順にエンシェントを並べ、名前の横に出会った回数を出す。

| 列 | 出し方 |
|---|---|
| 祝福 | 祝福の名前 |
| 提示回数 | 選択肢に出てきた回数 |
| 選択回数 | 選んだ回数 (数える列。最初はこの列で並べる) |
| 選択率 | 選択回数 ÷ 提示回数 |
| 勝率・勝率との差 | 選んだゲームについて、「表の共通の決まり」のとおり。選んだ回数が 0 なら「—」 |

## イベント

イベントを選ぶドロップダウンを置き、選んだイベントの選択肢ごとに 1 行を出す。ドロップダウンには、出会った回数の多い順にイベントを並べ、名前の横に出会った回数を出す。
エンシェントの階はイベントに含めない。ネオーの階も、選択肢が記録されていないとき (ブリッツでは記録に「ブリッツ」だけが入る) を含めて、イベントに含めない。

| 列 | 出し方 |
|---|---|
| 選択肢 | 選んだ選択肢の名前 |
| 選択回数 | 選んだ回数 (数える列。最初はこの列で並べる) |
| 勝率・勝率との差 | 選んだゲームについて、「表の共通の決まり」のとおり |

## マルチプレイ

- ソロの勝率とマルチプレイの勝率を、それぞれのゲーム数とともに出す。ゲームが無い方は「—」。
- 一緒に遊んだプレイヤーの表を出す。1 人につき 1 行。

| 列 | 出し方 |
|---|---|
| プレイヤー | 名前。その人のユーザーページへのリンク |
| ゲーム数 | 一緒に遊んだゲームの数 (数える列。最初はこの列で並べる) |
| 勝率 | 一緒に遊んだゲームの勝率 |
| 自分の与ダメージの割合 | 一緒に遊んだゲームごとに、全員が敵に与えたダメージのうち自分が与えた割合を出し、その平均。与ダメージの記録が無いゲーム (セーブデータの履歴から取り込んだゲーム) は平均に入れない |

## 数字の出どころ

各ゲームの数字は、ゲームの階ごとの記録 (`floor_snapshot`、階ごとに最後に届いたもの) と、ゲームの結果 (`run_end`)、敵に与えたダメージ (`damage_dealt` の `amount`) から出す。

| 値 | 記録の中の場所 |
|---|---|
| カードの提示と取った | `card_choices` (`was_picked`)。`rooms` に `Shop` がある階は除く |
| 持っていたレリック | `relics` |
| 敵と被ダメージ | `rooms` の戦闘の部屋 (`Monster` / `Elite` / `Boss`) の `model_id` と `model_name`、`hp.damage_taken` |
| 死んだ戦闘 | 死んだゲームの最後の階の戦闘の部屋 |
| Act | `act_index`。カードの提示の Act は、そのカードが出てきた階の `act_index` |
| ゲームのバージョン | セッションを作るときに mod が送る `game_version` (ゲームのフォルダの `release_info.json` の `version`)。この値を記録する前に作ったゲームは、すべて v0.113.1 とする |
| 休憩所の選択 | `rest_site_choices` |
| エンシェント | `ancient_choices` (`was_chosen`) がある階の部屋の `model_id` と `model_name` |
| イベント | `ancient_choices` が無く `event_choices` がある階の部屋の `model_id` と `model_name`、`event_choices`。部屋の `model_id` が `NEOW` の階は除く |

## ゲームごとの集計の保存

サーバは、ゲームと参加者の組ごとに集計を作り、`game_summaries` に保存する。統計のタブを開いたときと絞り込みを変えたときは、サーバは保存してある集計から条件に合うゲームを選び、足し合わせた結果だけを返す。

サーバが集計を作るのは、`run_end` が届いてセッションに勝利か死亡が記録された時点と、サーバの起動直後である。起動直後には、集計の作り方を変えたために古くなった集計と、まだ無い集計を作る。保存した後に同じゲームへ新しい記録が届いたら、次に統計のタブを開いたときに作り直す。

## 既知の制約

- 強化したカードを取ったかどうかは区別しない。
- イベントで出てきたが選ばなかった選択肢は、記録に無いので数えない。
- セーブデータの履歴から取り込んだゲームは、レリックがラン終了時点のものしか分からない。途中で手放したレリックは「レリック」の表に数えない。
